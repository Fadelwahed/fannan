Verify the pinned manifest at session start, resolve the project from settings, and run `"$FANNAN_RELEASE/tools/readonly-precheck.sh" "/workspace/design-output/<project>/" "<project>"` before writing `ui-map.md` there. See [security and install](../../references/security-and-install.md). Use read-only repo and preview access. Record actual stack, component library, tokens, pages, routes, states, copy and source paths, with unknowns marked unknown. Update at setup, after relevant repo change or when the map is stale. Keep dated design preferences in `taste.md`, separate from facts.

Never branch, commit, push, open PRs, modify repo files, or invent missing UI. Report code problems to the project's engineer.

## Gotchas

- A screenshot alone cannot establish a hidden state, source component or approved copy.
