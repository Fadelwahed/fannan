## Panel

q1: POSITION: Keep failing the final handoff on any frame for now, and add a scoped, reviewed `frameExceptions` entry rather than auto-scanning same-origin frames. Make "scan same-origin frames, fail only unreadable ones" the target once every gate actually runs inside frames.
REASONS:
- Today only glass and a 320 px scrollWidth look inside frames. axe, focus/target size, copy, contrast, spacing, the integrity cross-check and reduced motion do not. Scanning same-origin frames for glass alone would turn "not checked" into PASS, which breaks the WCAG 2.2 AA floor.
- Real embedded maps and video are cross-origin, so the resource boundary already blocks them and fails the run. Relaxing the frame rule alone would not help them. The honest design deliverable is a static poster or placeholder plus an engineering note in the handoff.
- A `frameExceptions` entry (screen/state/lang, element id, reason, qaGate/approver reviewer, required manual a11y evidence) matches the existing `reflowExceptions`/`spacingExceptions` discipline.
- Same-origin frames can be scanned later: run every probe via Playwright `frame.evaluate` in a per-frame isolated world, run axe with frames enabled, and add frames to the integrity vector. Only then switch to "unreadable frames fail".

q2: POSITION: Not safe as written. Allowing plural `tokens` is fine only for real design-token files, identified by path or content, not by name.
REASONS:
- `tokens.json`/`tokens.txt` is a common credential file name (OAuth token caches in googleapis/gcloud samples, CLI token stores). The current rule lets every `tokens.*` through, with any allowlisted suffix.
- The singular/plural split is weak anyway, because prefixed names like `api-token.json` and `oauth-tokens.json` pass too (R13-OPUS-08).
- Safer with no new dependency: allow `tokens.json` only when its path equals the handoff `tokens.json.path`, or when it parses as DTCG (every leaf has `$value`, no `access_token`/`refresh_token`/`client_secret` keys). Refuse it otherwise.
- Also add an automated stdlib-regex content screen for obvious secrets (`-----BEGIN`, `AKIA[0-9A-Z]{16}`, `"refresh_token"`) on packaged files. That closes the "secrets inside ordinarily named files" gap that is currently manual.
